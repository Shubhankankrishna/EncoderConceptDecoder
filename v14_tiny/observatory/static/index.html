How to read this dashboard

NTP loss

Next-token prediction error. Compare within a task family; lower is better.

NCP loss

Prediction error for future concept codes. It needs baseline comparisons to establish usefulness.

Global residual b

Information beyond the predictable local contribution. V14 tests whether the concept path learns it.

Code perplexity

The effective number of codes used, up to 32 per segment. This differs from text perplexity.

Forgetting

Loss of performance on earlier learned tasks. Lower is better; backward transfer can be negative.

Freshness

UI polling, host sampling and training logs have separate clocks. A dashboard refresh does not mean a new training step was logged.
