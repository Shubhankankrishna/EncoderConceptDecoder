# V6/V7 lessons carried into the executable V8 pilot

The review covered the model, document packing and symbolic generators, objectives and optimizers, fast/full generation, public verifier, exploration/repair/tree search, queue order, benchmark/audit code and saved training/development evidence in both `v6_tiny` and `v7_tiny`. Historical source/result hashes are recorded in `historical_sources.json`; nothing in those folders was edited.

The V6 alpha-zero checkpoint has2,022,144 parameters,9,000 training updates and288,032 logged graph instances (the log includes the32-instance initialization probe). V7 NCP seed171 has5,365,938 parameters,3,826 updates and36,713 GraphNav training examples. V7's25M-target stop favored text/formatting targets and did not preserve graph exposure. V8 therefore counts updates and individual task examples, and initialization uses an independently seeded probe outside the exposure counter.

Historical V6 development replay in the new decoder reproduced51/64 standard and37/128 hard successes. The matched9,000-update NCP checkpoint gave0/64 and0/128. These small inspected development comparisons motivate alpha-zero versus delayed alpha0.1, but do not establish that NCP is ineffective at scale or that this new recipe will work.

V7 coupled a larger model with fewer graph examples, larger graphs, initialization/QK/routing changes and a token-based horizon. Its flat baseline also failed navigation. V8 keeps plain V6-style blocks and initial10-node graph training, with a separate parameter-matched flat baseline. A fresh simple retrieval/composition gate comes before any large matrix; the hard384-position continuation comes after actual competence and is separately accepted.

The V7 queue's refit/exploration/search could advance before establishing useful backbone skill. Preservation of zero graph success could be called accepted. V8 requires absolute lookup/first-move/standard success as well as paired retention; failed/unresolved candidates remain archived but are not promoted.

The old generation path assumed certain aligned prefixes, and V7's stop test accepted `<done>` anywhere in a four-token response chunk. V8 pools only complete chunks, refreshes from actual generated tokens, handles all prefix remainders, stops graph walking only on a first-slot terminator, and treats fixed four-token lookup/binding answers explicitly. Cache contracts now include trained V6 graph prompts and six recurrent execution visits, not just short text or a fresh model. Historical successes remain identical under the new verifier.

Compiled Metal execution is tested against eager parameter gradients rather than inferred from speed. The recurrent exploration path failed the relative-gradient criterion and is pinned to eager. Other passing paths retain compilation. The production end-to-end foundation check measured about47k slots/s and27k scored targets/s; padded slots and scored targets are distinct.

V8 exploration is a smooth, zero-anchored, separately trained continuous intervention; soft PQ/NCP does not make the whole module discrete. Search records full actual answers/control histories and charges prefill, repair, verifier and allocation costs. Prior coverage gates prevent a large all-zero search study. Public graded feedback and nonadaptive/same-kernel controls distinguish proposal quality from allocation; a successful search RNG repeat is not an independent trained model.

LSL adds task learning and gate installation as separate measurements. Old distributions are withheld from gradient optimization, but generic negative-density fitting uses disclosed reference data containing old graph responses. New banks must learn while forced open before a support gate is blamed; old-task adjacent and cumulative retention are checked after installation. The complete12-hour pilot matrix and its deferred controls are stated before launch, rather than being inferred from whichever stages survive.
